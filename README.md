# agenticOpsMarketingCloud
This repository houses two Apex classes designed to interact with Salesforce Marketing Cloud's APIs, enabling Agentforce with email creation and Journey Builder functionality.

CreateMarketingCloudEmail focuses on generating emails within Content Builder.  It leverages the Marketing Cloud REST API to programmatically construct email content, including subject lines, preheaders, and the email body itself (supporting both plain text and HTML).  The class accepts parameters for these elements, allowing for dynamic email creation based on Salesforce data or external triggers.  It then sends the API call to Marketing Cloud through the context of Agentforce, returning the newly created email's ID.  Error handling is included to manage API failures and provide informative feedback.

JourneyBuilderAPIService facilitates interaction with Journey Builder, again via Agentforce assistant interaction.  This class provides methods to trigger entries into pre-defined journeys.  It uses the Marketing Cloud SOAP API to authenticate and subsequently inject contacts into a specified journey.  The class requires the Journey ID and the subscriber key (typically the Contact ID or Lead ID from Salesforce) as input.  It constructs the necessary SOAP request, sends it to Marketing Cloud, and parses the response to confirm successful entry.  Similar to the CreateMarketingCloudEmail class, it incorporates error handling and logging to ensure robust operation.  Together, these classes provide a foundation for automating email creation and journey orchestration directly from within Agentforce, streamlining marketing processes and enhancing campaign management.  The repository includes example usage within a test class demonstrating how to call these services.
